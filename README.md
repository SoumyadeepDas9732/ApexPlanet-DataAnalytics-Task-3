# ApexPlanet Data Analytics Internship
## Task 3: Deep-Dive Analysis & Interactive Dashboarding

### Objective
To perform an in-depth analysis of sales and customer behavior and build
an interactive business intelligence dashboard.

### Core KPIs
- Total Revenue
- Total Orders
- Average Order Value
- Unique Customers
- Average Revenue per Customer

### Deep-Dive Analysis
Customer Segmentation & Sales Performance Analysis

Customers were segmented into:
- High Value
- Medium Value
- Low Value

### Analysis
The project includes:
- Customer segmentation
- Revenue contribution analysis
- Product analysis
- Category analysis
- Geographic analysis
- Monthly trend analysis

### Interactive Dashboard
An interactive dashboard was developed to monitor the core KPIs and
allow filtering by customer, product, location and time dimensions.

### Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
- Looker Studio
